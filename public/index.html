About Nabz

Nabz is a React Native health report application that makes laboratory test results easy to understand. We present complex medical data in simple, actionable insights available in both English and Hindi.

Features

  • View all your laboratory reports in one place
  • Easily identify abnormal test results with flagging
  • Bilingual support (English & Hindi)
  • Responsive design for mobile and desktop
  • Categorized test results by type

Technology Stack

  • React Native - Cross-platform mobile framework
  • Expo - React Native platform
  • React Navigation - Navigation management
  • Vercel - Hosting & deployment
